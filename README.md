# CCAPDEV-MCO-Database

=========================================

Project Description

Lab Reservation System for students to reserve lab seats to access computers
includes details regarding the reservation,
student profile page to edit their own information

=========================================

package.json
Dependencies
- Express
- Mongoose
- Session
- Handlebars
- bcrypt

To Run
- Install the zip file
- Open file in code editor
- run 'npm install' in terminal to install the dependencies
- open MongoDB Compass to connect database
- run the file server.js
- open the website in web browser - http://localhost:3000
